# Etichette delle issue

Le issue stanno nelle GitHub Issues di `<owner>/<repo>` e si gestiscono con la CLI `gh`. Ogni issue ha un'etichetta di triage, almeno una d'area e una di tipo. Triage e tipi sono quelli del metodo di lavoro (skill `antoniovirgone-skills:metodo-di-lavoro`), uguali in tutti i progetti; qui ci sono le aree di questo progetto.

## Area

Dicono **dove** si svolge il lavoro. Un'issue che tocca più aree le porta tutte.

| Etichetta | Dove si svolge il lavoro |
| --- | --- |
| `<area>` | <cartelle, strumenti, servizi> |
